# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private vulnerability reporting instead:
[**Report a vulnerability**](https://github.com/chelsey-g/ai-quiz-app/security/advisories/new)
(repo **Security** tab → **Report a vulnerability**).

Include steps to reproduce and the impact you've identified. You'll get an
acknowledgement within a few days, and an update once the issue is confirmed and
a fix is planned.

## Scope

This is a hobby project with no formal support commitment, but security reports
are taken seriously and will be addressed as quickly as is practical.
